Experience

Firmware engineer intern, Nova Robotics (Santa Clara, February 2025 to March 2026)

Nova Robotics builds a dual-reaction-wheel humanoid robot. Website: https://www.novarobotics.us/

  • Engineered real-time PID and LQR control for the dual-reaction-wheel humanoid on ROS 2 with a URDF model, enabling dynamic self-balancing.
  • Implemented a cyclic-coordinate-descent inverse-kinematics solver for autonomous walking and squatting.
  • Wired IMUs, motor drivers and cameras to a Raspberry Pi over I2C, SPI and CAN.
  • Validated controllers in Isaac Sim and MuJoCo before running them on the robot (sim-to-real transfer).
  • Integrated Unity and OpenXR with WebRTC for two-axis head and controller teleoperation at under 100 ms end-to-end latency.
  • Stack: ROS 2, C++, Python, Isaac Sim, MuJoCo, Unity, WebRTC, CAN.
  • Video, 10 seconds, portrait: https://devmello.xyz/videos/nova-humanoid.mp4. The humanoid balances on one leg and switches legs while its two reaction wheels hold it upright.

Co-founder and software lead, CometKits (Santa Clara, since 2022)

CometKits makes low-cost robotics kits for elementary schools. Website: https://cometkits.github.io/

  • Each kit is a small programmable car: a custom PCB around an Arduino Nano (ATmega328), a 3D-printed chassis, motors and an IMU, with a curriculum aligned to the Next Generation Science Standards.
  • Built the software, including a browser-based Blockly editor that transpiles blocks to C++, compiles it and loads it onto the car, so a student's first program runs on real hardware.
  • The program has reached hundreds of students across five Santa Clara elementary schools and has been recognized by the city's mayor and covered by NBC Bay Area.
  • NBC Bay Area segment, "South Bay high school robotics team bringing sport to next generation": https://www.youtube.com/watch?v=p5Mq5VVSzcs
  • Stack: Arduino, C++, Blockly, JavaScript.

typethru (2026)

  • Apply a git diff by retyping it. typethru reverts what a coding agent wrote and feeds it back hunk by hunk, verifying every keystroke, until the working tree is byte-identical to the agent's version. Lockfiles, whitespace and deletions apply themselves, and a plan screen prices each file in minutes at the user's own typing speed.
  • Install: pip install typethru
  • Code: https://github.com/DevMello/typethru. Write-up: https://blog.devmello.xyz/blog/the-slowest-way-to-apply-a-diff/
